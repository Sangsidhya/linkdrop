# LinkDrop (Made with ClaudeAI )

AirDrop-style sharing between **Windows** and **Android** over the same Wi-Fi or phone hotspot.

- Send files both ways (drag & drop on PC)
- Send text both ways
- Automatic clipboard sync both ways while the app is running
- One-time QR pairing, TLS 1.3 with certificate pinning, no cloud, no internet needed

## Download
Grab the latest `linkdrop-android.apk` and `linkdrop-windows.zip` from **Releases**
(or from the **Actions** tab → latest run → Artifacts).

## Install
- **Android (8.0+):** open the APK and allow "Install unknown apps".
- **Windows:** unzip anywhere and run `linkdrop.exe`. If SmartScreen appears: *More info → Run anyway*.
  Allow it in Windows Firewall (tick **Public** too if your hotspot is marked Public).

## Use
1. Connect the PC to the phone's hotspot (or the same Wi-Fi).
2. PC: **Pair device** → Phone: **Scan**.
3. Drop files, send text, or just copy — it appears on the other device.
4. Close the PC window / swipe the app away on the phone to turn it off.
